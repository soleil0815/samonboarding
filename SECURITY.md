# Reporting security vulnerabilities / Sicherheitslücken melden

*Deutsche Fassung unten.*

## English

SAMONBOARDING works with far-reaching rights in Active Directory. If you find a security vulnerability, please do **not** report it publicly (no issue, no discussion) but confidentially:

- on GitHub under **Security → Report a vulnerability** (private report to the maintainer).

Helpful: affected version (see *Help → News*), Samba AD or Windows Server AD, steps to reproduce and the possible impact. Please do not include real passwords, personal data or extracts from a production AD.

The project is maintained in spare time. Reports are read and handled with priority according to their severity; there are no fixed response times. Fixes are made for the **newest version** only. Please publish details only once a fixed version is available or after agreement.

## Deutsch

SAMONBOARDING arbeitet mit weitreichenden Rechten im Active Directory. Wenn du eine Sicherheitslücke findest, melde sie bitte **nicht öffentlich** (kein Issue, keine Diskussion), sondern vertraulich:

- auf GitHub unter **Security → Report a vulnerability** (private Meldung an den Betreuer).

Hilfreich sind: betroffene Version (steht unter *Hilfe → Neuigkeiten*), Samba AD oder Windows Server AD, Schritte zum Nachvollziehen und die mögliche Auswirkung. Bitte keine echten Passwörter, Personendaten oder Auszüge aus einem produktiven AD mitschicken.

Das Projekt wird in der Freizeit gepflegt. Meldungen werden gelesen und nach Schwere vorrangig bearbeitet; feste Antwortzeiten gibt es nicht. Korrigiert wird jeweils nur die **neueste Version**. Bitte veröffentliche Details erst, wenn es eine korrigierte Version gibt oder nach Absprache.
